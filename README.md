# SmartCash

Aplicação web de controle financeiro pessoal desenvolvida com HTML, CSS e JavaScript puro.

## Funcionalidades
- Registro de transações (entradas com valores positivos e saídas com valores negativos)
- Resumo em 3 cards (**Entradas**, **Saídas** e **Saldo Total**) com feedback visual
- Extrato em ordem cronológica com exclusão individual
- Persistência de dados no `LocalStorage` e alternância entre temas escuro e claro
